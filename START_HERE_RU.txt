3. LINUX

В терминале папки Campus_Lost_Found выполни:
    bash START.sh
После подготовки окружения:
    bash TESTS.sh

Нужны Bash, Python 3.10+, venv/ensurepip и Интернет при первой установке зависимостей. Linux-окружение создаётся отдельно в пользовательском cache; Windows python.exe и vendor на Linux не используются. Заранее установи зависимости и проверь работу без Интернета. Подробности: Campus_Lost_Found/START_LINUX_RU.txt.
Фактический запуск Linux/WSL ещё не проверен. Если старая вложенная инструкция упоминает 65 тестов, актуальный размер набора — 72.

5. ЧТО ИСПРАВЛЕНО И ЧТО ЕЩЁ НУЖНО ПРОВЕРИТЬ

Очень большие числовые значения в фильтрах и адресах объявлений теперь получают контролируемый ответ 400/404 вместо ошибки сервера. Обычные фильтры, страницы и прежние безопасные варианты обработки ввода сохранены.
Создание и чтение полного backup теперь используют общий предел manifest 1 MiB. Слишком большой manifest отклоняется до публикации ZIP; значение ровно на границе принимается. Подробности и ограничения — в Technical_Verification.txt.

Для B1/B2 нужны ровно пять реальных добровольцев вне команды и две задачи на человека. Наблюдатель использует /admin/research: Start timer → Stop timer сразу после задачи → итог, помощь и заметки → Save final observations. Первые самостоятельные попытки сохраняются, неудачи не заменяются. Пороги: 4/5 публикаций за ≤120 секунд и 4/5 поисков за ≤60 секунд. До всех десяти завершённых попыток результат Pending. Инструкции: Testing/INSTRUCTIONS_RU.txt и Testing/TASK_CARDS_EN.txt. Наблюдения и три проблемы B2 нельзя выдумывать.

Три браузерных замера Fast 4G с отключённым cache, текущая проверка 360 px, клавиатуры и offline/retry пока не выполнены. Порядок: Testing/BROWSER_EVIDENCE_RU.txt. Старый результат поиска 81,47 ms p95 — локальные HTTP-запросы без assets и отрисовки; он не заменяет браузерный замер загрузки.
