Проверка браузера и скриншоты для Endterm

Это инструкция для оставшейся проверки, а не уже полученные результаты.
Серверная проверка поиска и 65 автоматических тестов не заменяют этот пункт.

1. Скриншоты текущего прототипа
Запусти START.bat (Linux: bash START.sh), открой 127.0.0.1:5055.
Для каждого шага сохраняй обычный PNG скриншот без личных вкладок и уведомлений.
Используй отдельную демонстрационную вкладку и только вымышленные данные.

A1-01: вход студента и главная страница.
A1-02: заполненная форма Post a notice до публикации.
Пример: Found / Books and Stationery / Endterm blue notebook / Library study area.
Описание: Fictional blue notebook with a star sticker for our classroom demo.
Дата: фактическая дата демонстрации; фото необязательно.
A1-03: опубликованное объявление с номером и сообщением об успешном сохранении.
A1-04: поиск этого названия с категорией Books and Stationery.
A1-05: страница объявления с Contact author. Это mailto, реальную почту не отправляй.
A1-06: Edit my notice, изменение описания, затем сохранённое описание после обновления.
A1-07: Mark as returned и видимый Returned после обновления.
A1-08: вход администратора, то же объявление и Remove notice.
A1-09: страница подтверждения удаления именно созданного тестового объявления.
A1-10: список после удаления, где тестового объявления больше нет.
C5-01: Analytics под администратором, счётчики и один график.
D3-01: Smart locker с меткой SIMULATED и открытым состоянием.
D3-02: через 10 секунд нажми Refresh: предупреждение; затем закрой симуляцию.

Если создавал и затем удалил только своё демонстрационное объявление, основная
аналитика снова содержит 122 объявления. Не удаляй исходные записи или результаты
реальных тестировщиков, чтобы подогнать показатели к отчёту.

2. Три замера Fast 4G
Войди как студент, открой главную страницу. Открой DevTools (F12 или Ctrl+Shift+I),
выбери Network. Включи Disable cache, выбери Fast 4G в списке скорости.
DevTools должен оставаться открытым. Сохраняй одинаковый размер окна.
Для каждого из трёх запусков: очисти список запросов, обнови страницу, дождись
загрузки. Запиши Load (мс), Transferred и число Requests. Сохрани скриншот,
на котором видны Fast 4G, Disable cache и итоговые значения. Файлы B3-01..03.png.
Если DevTools показывает секунды, переведи в мс: 1 s = 1000 ms.
Среднее = (Load1 + Load2 + Load3) / 3. Не смешивай Load, Finish и DOMContentLoaded.
Отдельный server p95 81.47 ms относится к 100 запросам поиска с 10 сессиями;
его нельзя подставлять вместо браузерного среднего.

3. 360 px, клавиатура и восстановление
В DevTools включи responsive mode, ширина 360 CSS px. Открой регистрацию,
список, форму, объявление и три страницы администратора. Проверь, что основной
контент доступен без горизонтальной прокрутки; таблицы могут иметь собственный
доступный горизонтальный скролл. Сохрани проблемные места и один общий экран.
Пройди Tab/Shift+Tab по основным элементам; фокус должен быть виден, подписи
полей понятны, кнопки активироваться Enter/Space. Укажи фактический результат.
В Network выбери Offline и обнови страницу: приложение не обещает автономную
работу при недоступном сервере. Верни No throttling, повтори загрузку и проверь,
что сохранённое объявление осталось в базе. Зафиксируй ошибку/восстановление.
После проверки верни обычную сеть, размер окна и закрой DevTools.
