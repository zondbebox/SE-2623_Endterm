ЗАПУСК WINDOWS
1. Полностью распакуй архив и открой папку Campus_Lost_Found.
2. Дважды нажми START.bat. Не закрывай окно сервера.
3. Открой http://127.0.0.1:5055 в браузере.
Встроенный Python и библиотеки входят в комплект; для Windows Интернет не нужен.
Если порт 5055 занят, останови другую копию проекта. Ctrl+C останавливает сервер.

ЗАПУСК LINUX
В терминале из этой папки: bash START.sh
Нужны Bash, Python 3.10+, venv и Интернет для первой установки закреплённых
зависимостей, включая Pillow. Затем возможен запуск без Интернета.
Подробности: START_LINUX_RU.txt. Windows python/, vendor/ и media_vendor/
не являются средой Linux. В этой Windows-среде WSL не установлен;
запуск и установка Linux здесь не проверялись.

ОСНОВНОЙ СЦЕНАРИЙ
Create a local student account: регистрация адреса формата @astanait.edu.kz
с новым локальным паролем 12–128 символов. Домен проверяется по формату,
владение адресом не подтверждается. Не вводи настоящий университетский пароль.
Browse notices: поиск по названию, категории и статусу.
Post a notice: создание объявления; необязательно один JPG/PNG до 5 МБ
и 12 миллионов пикселей. Фото заново кодируется, метаданные удаляются,
размер уменьшается до 1600 пикселей по большей стороне. Хранилище закрыто
от прямого статического доступа; фото доступно только после входа.
My notices: редактирование своей записи и Mark as returned. Пустое поле
фото при редактировании сохраняет старое фото; новое фото заменяет старое.
Contact author: открывает черновик в почтовой программе. Сайт сам не
отправляет письма. Адреса исходных demo-аккаунтов вымышленные.
Администратор может удалить объявление после подтверждения.

СТРАНИЦЫ АДМИНИСТРАТОРА
Analytics: три SQL-анализа, диаграммы, таблицы и CSV. Данные синтетические;
выводы не описывают реальную активность кампуса.
User testing: только реальные пять добровольцев вне команды. Для каждого
одна первая попытка Publish и одна Find. Нажимай Start в начале и Stop
сразу по завершении/отказу; заметки вводятся после остановки таймера.
Не вводи тренировочные или автоматические результаты как пользовательские.
Smart locker simulation: явно обозначенная программная симуляция без
оборудования. После Simulate open обнови страницу через 10 секунд для
предупреждения. Если связанное объявление удалено или изменено на Lost,
Reset unavailable assignment сохраняет историю и записывает новое
SIMULATED-состояние Closed / Unassigned. Объявления не изменяются.

ПРОВЕРКИ И ДАННЫЕ
TESTS.bat / bash TESTS.sh запускают 65 автоматических проверок и
останавливаются при первой ошибке. Тесты используют временные данные.
DATABASE.bat / bash DATABASE.sh: отдельный инспектор SQLite только для
чтения по http://127.0.0.1:8088. Основная база: data/campus.sqlite3.
Исследование: data/research.sqlite3; симуляция: data/telemetry.sqlite3.
Фотографии: data/uploads. Дополнительные базы создаются при первом использовании.

ПОЛНАЯ РЕЗЕРВНАЯ КОПИЯ
Приостанови изменения в приложении для согласованности отдельных файлов.
Windows: BACKUP.bat. Linux: bash BACKUP.sh.
Создаётся backups/campus_full_*.zip: онлайн-снимки баз SQLite, фотографии
и manifest.json с SHA-256. runtime/session.key и audit.jsonl не включаются.
Windows: RESTORE_CHECK.bat. Linux: bash RESTORE_CHECK.sh.
Проверка последнего полного ZIP создаёт НОВУЮ папку data/restore_checks,
проверяет пути, хеши, целостность и числа строк; рабочие данные не заменяются.
Это проверка восстановления, а не автоматическая подмена рабочей папки.
Команды DB.bat / bash DB.sh backup и restore-check остаются отдельными
командами ТОЛЬКО основной базы; они не включают фотографии и другие базы.
При переносе между ОС сначала останови приложение и инспектор.
